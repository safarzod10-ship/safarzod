# CardArena — Mobile Demo v0.1

Интерактивный мобильный прототип коллекционной платформы для Telegram Mini Apps.
Один файл, без сервера, без внешних библиотек и сетевых запросов.

```
cardarena/
├── index.html                 # всё приложение (HTML + CSS + JS)
├── assets/
│   └── cardarena-avatar.png   # ← сюда положить ОФИЦИАЛЬНУЮ аватарку CardArena
├── tests/
│   ├── e2e.js                 # сценарии Playwright (виртуальные часы)
│   └── screenshots/           # скриншоты последнего прогона
└── .gdignore                  # чтобы Godot-проект не импортировал папку
```

## Запуск

Открыть `index.html` в мобильном браузере или раздать папку любым статическим сервером:

```bash
cd cardarena && python3 -m http.server 8080   # → http://<ip>:8080
```

Логотип загружается из `assets/cardarena-avatar.png` (относительный путь).

## Что реализовано

| Раздел | Содержание |
|---|---|
| Главная | логотип + название, баланс, аватар, два активных аукциона (превью, имя, ID, редкость, таймер, участники, статус, «Открыть»), раздел «Итоги» |
| Карточки | #1111 Golden Dragon (Mythic, 1/1): ар-деко медальон, вставший на дыбы дракон. #2026 Shadow Wolf (Legendary, 1/1): готическая арка, луна, низкополигональный волк. Две разные оригинальные SVG-композиции |
| Аукцион | «Назад», статус, крупная карточка с появлением, бликом рамки и наклоном, ID/редкость/тираж, таймер 00:20 (янтарный акцент в последние 5 с, без мигания), участники с шансами, «Участвовать бесплатно» → «Вы участвуете» |
| Розыгрыш | 20 с, абсолютный `endAt`, минимум 2 участника, равные шансы, победитель через `crypto.getRandomValues` (rejection sampling, без смещения по модулю), результат сохраняется **до** анимации |
| Рулетка | полноэкранная лента, указатель, easeOutQuart ≈5,2 с, `transform` + `requestAnimationFrame`, остановка ровно на заранее выбранном победителе, «пропустить» по ✕ |
| Коллекция | свои карточки, пустое состояние с иллюстрацией, экран карточки (дата, история получения) |
| Рейтинг | 10 демо-профилей + позиция пользователя, компактный список |
| Профиль | статистика, история розыгрышей, достижения, операции, настройки (звук, анимации, сброс, о приложении) |
| Хранение | `StorageManager` (единственное место работы с localStorage, с fallback в память), версия схемы, миграции, валидация, восстановление при повреждении |

Структура кода внутри `index.html`: `StorageManager`, `StateManager`, `CardManager`,
`AuctionManager`, `ProfileManager`, `RouletteController`, `NavigationController`,
`RevealQueue`, `UI` / `View` / `Screens`, `SoundManager`, `TelegramBridge` (неактивен, пока нет
Telegram SDK).

Жизненный цикл раунда: `Scheduled → Active → Drawing → Completed` и `→ Cancelled`.
Переходы проходят через одну таблицу, недопустимый переход выбрасывает ошибку.

## Ограничения

- Сервера нет, поэтому локальные данные **не защищены** от подделки. Валидатор лишь отсекает
  несогласованные состояния (например, карточку без соответствующей победы).
- Если открыты две вкладки ровно в момент завершения, каждая может провести розыгрыш. Затем
  вкладки сходятся к последней записи через событие `storage`. Настоящий арбитраж требует сервера.
- При «Сбросить демо» сохраняются настройки (звук, анимации), всё остальное пересоздаётся.

## Тесты

```bash
cd cardarena
node tests/e2e.js          # 75 проверок
SHOTS=1 node tests/e2e.js  # + скриншоты в tests/screenshots
```

Проверяются сценарии A–H, навигация, настройки, обновление на 10-й секунде, обновление ровно в
`endAt`, закрытие до завершения, сбой между `Drawing` и `Completed`, одновременное завершение
двух раундов, отсутствие двойной выдачи, две вкладки, `prefers-reduced-motion`, распределение
случайного выбора, недоступный localStorage, повреждённые/будущие/несогласованные данные,
миграция v0→v1, ширины 320/360/393/412/430 (нет горизонтального скролла, кнопка и навигация не
перекрывают контент).

Не проверялось: реальные Android-устройства и Telegram WebView. Проверки шли в headless Chromium
с мобильной эмуляцией.
