# Сервер: Telegram-бот и рейтинг игроков

Код: `server/worker.js` (Cloudflare Worker `dvor-server`, адрес `https://dvor-server.dvor-game.workers.dev`).

| Путь | Что делает |
|---|---|
| `POST /tg` | вебхук Telegram (проверяется секретный заголовок): `/start` — история и кнопка «Играть», `/top` — лучшие 10, `/help` |
| `POST /api/result` | Mini App после боя присылает кубки, уровень, героя; подпись Telegram (initData) проверяется на сервере |
| `GET /api/top` | топ-50 по кубкам; ответ кэшируется на минуту |
| `POST /api/game-score` | результат боя, открытого из игрового сообщения (вызов или /play в группе): таблица рекордов этого чата (`setGameScore`) и общий рейтинг; игрок определяется подписанным токеном из кнопки «Играть» |

## С друзьями: вызов через @dvor_app и группы

- **Вызов в любом чате**: в поле ввода пишешь `@dvor_app` — появляются варианты: игра «ДВОР» (кнопка «Играть»,
  рекорды прямо в сообщении), «Вызов на бой» (текст с твоими кубками и кнопкой «Принять вызов») и «Рейтинг двора».
- **В группе**: добавить бота, `/play` — игровое сообщение с кнопкой «Играть» и таблицей рекордов этой группы;
  `/top`, `/help` тоже работают. На обычные сообщения группы бот не отвечает.
- Кнопки в группах ведут на `https://t.me/dvor_app?startapp=...` — это прямая ссылка на Mini App.

Что нужно включить в @BotFather (сам бот этого сделать не может):
1. `/setinline` → @dvor_app → подсказка, например «вызвать на бой» — без этого `@dvor_app` в поле ввода не работает.
2. `/newgame` → @dvor_app → название «ДВОР», описание, картинка 640×360 (`telegram/game_640x360.jpg`),
   GIF — пропустить, короткое имя — **dvor** (именно так, сервер ждёт это имя). Без игры вызов работает
   ссылкой, но без рекордов в сообщении.
3. Bot Settings → Configure Mini App → Enable Mini App, адрес `https://safarzod10-ship.github.io/safarzod/` —
   чтобы ссылки `t.me/dvor_app?startapp` из групп открывали игру.
4. `/setjoingroups` — Enable (обычно уже включено).


Хранилище: D1 `dvor` (таблицы `players`, `meta`). Секреты `BOT_TOKEN` и `WEBHOOK_SECRET` лежат только в
Cloudflare (не в репозитории). `WEBAPP_URL` — адрес игры на GitHub Pages.

Бесплатный тариф: одна запись в D1 на законченный бой (и не чаще раза в 20 секунд на игрока), рейтинг отдаётся
из кэша, Durable Objects (комнаты для онлайна) пока не используются. Лимиты: 100 000 запросов к Worker в сутки,
5 млн чтений и 100 000 записей D1 в сутки — с запасом.

Ограничение: кубки считает телефон игрока, сервер только проверяет, что запрос пришёл из Telegram. Подделать
результат можно; защиту даст только онлайн, где бой считает сервер.
