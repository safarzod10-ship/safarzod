# Night Blade — Telegram Mini App (прототип)

Оригинальная 2D-экшен-игра для мини-приложения Telegram: ниндзя с катаной против волн врагов, смерть с одного удара.
Чистый HTML5 + JavaScript, без сборки и зависимостей, графика рисуется кодом (чужих ассетов нет).

## Что уже есть
- Игра: бег, прыжок (короткий/длинный), удар катаной, рывок с неуязвимостью.
- Враги: громила с трубой (замах — красный сигнал), стрелок (лазерный прицел, пулю можно отбить ударом обратно), щитовик (бить со спины, разворачивается медленно).
- Волны, комбо-множитель, бонус за волну, кровь, тряска экрана, замедление при смерти, неоновый город с параллаксом и дождём.
- Управление: сенсорные кнопки (мультитач) и клавиатура (A/D, Space, J, K, Esc).
- Telegram: `ready/expand`, отключение свайпа закрытия, цвета шапки, кнопка «Назад», вибро-отклик (HapticFeedback), имя игрока.
- Слой ставок: баланс, ставка 0/10/25/50 ⭐, таблица множителей по очкам, экран результата. **Сейчас это ДЕМО**: звёзды хранятся в браузере и ненастоящие.

## Файлы
- `index.html` — экраны (меню, HUD, кнопки, пауза, результат) и стили.
- `game.js` — игра.
- `api.js` — слой бэкенда: `getProfile`, `startRun`, `finishRun`. Сейчас демо-режим (localStorage).

## Как подключить к боту
1. Включить GitHub Pages: Settings → Pages → Branch `tg-miniapp`, папка `/ (root)` → адрес вида
   `https://safarzod10-ship.github.io/safarzod/`. (Пока Pages не включены, можно временно взять адрес raw.githack.)
2. В @BotFather: `/mybots` → бот → Bot Settings → Menu Button (или `/newapp` для Mini App) → вставить HTTPS-адрес.

## Что нужно для настоящих звёзд (следующий этап)
- Сервер (Node/Python), адрес в `API_BASE` в `api.js`.
- Проверка `initData` подписи Telegram на каждом запросе.
- Баланс и результат считаются **на сервере**; клиент присылает лог событий (`log`), сервер проверяет его. Счёт с клиента принимать на веру нельзя — накрутят.
- Покупка звёзд — счёт через бота: `createInvoiceLink` с валютой `XTR`.
- Перед запуском проверить правила Telegram для игр с вознаграждением и законы страны: выплаты по результату ставки могут считаться азартной игрой.
