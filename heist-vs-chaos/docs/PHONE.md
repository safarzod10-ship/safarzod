# Управление с телефона

Откройте приватную ссылку `https://ВАШ-АДРЕС/panel/#t=ТОКЕН` (её выводит установщик) и добавьте страницу на главный экран. После первого открытия токен сохраняется в браузере и убирается из адресной строки. Без токена пульт ничего не показывает: публичная страница игры не даёт доступа к управлению. После 8 неверных попыток адрес блокируется на минуту.

| Раздел | Что можно |
|---|---|
| Шапка | статус эфира, статус Kick, отметка AUTO MODE |
| Stream | **START / STOP STREAM**, сколько уже в эфире и сколько осталось из 5 часов, FPS и скорость кодера, видит ли Kick эфир; настройки ключа, качества, режима 5 ч / 24/7, тест кодера |
| Game | уровень, фаза, HP, попытка, текущие голоса; пауза, продолжение, перезапуск уровня (с подтверждением) |
| Test interventions | крупные кнопки SCAN, SHIELD, REVOTE, REVIVE, CHAOS (на экране помечаются TEST) и журнал |
| Kick | статус, адрес webhook, подписки, последние события, счётчики отклонённых подписей; ключи приложения; эффекты подарков |
| Sound | громкость master / music / sfx / voice (применяется в эфире сразу) |
| Problems log | последние ошибки без секретов |
| Maintenance | резервная копия, перезапуск сервиса, **сброс прогресса** (нужно ввести RESET; копия базы делается автоматически), выход |

Перезапуск сервиса безопасен: игра продолжится с сохранённого состояния, эфир поднимется сам, если был включён.
