# Эксплуатация

Помощник `hvc` устанавливается вместе с игрой.

| Команда | Что делает |
|---|---|
| `hvc status` | состояние контейнеров и `/healthz` |
| `hvc logs` | последние 200 строк лога игры (без секретов) |
| `hvc stop` / `hvc start` / `hvc restart` | остановка, запуск, перезапуск |
| `hvc backup` | резервная копия базы сейчас |
| `hvc update [версия]` | обновление (перед ним делается копия базы) |
| `hvc rollback` | возврат к образу, который работал до последнего обновления (даже если оба были `latest`) |
| `hvc restore data/backups/ФАЙЛ.sqlite` | восстановление из копии (текущая база сохраняется рядом) |

## Резервные копии
Игра раз в сутки (проверка каждый час и через 30 с после старта, поэтому частые перезапуски не мешают) делает копию `data/backups/heist-daily-*.sqlite` (`VACUUM INTO` — согласованная копия без остановки) и хранит 14 последних. Ручные копии и копии перед сбросом прогресса (`heist-manual-*`) хранятся отдельно, 10 последних, поэтому они не вытесняют ежедневные. Установщик сохраняет `.env.backup`. **Храните копию `.env` в надёжном месте:** без `SECRET_KEY` сохранённые ключи Kick и трансляции придётся ввести заново. Чтобы хранить копии вне сервера, скачивайте `data/backups/` (например, через SFTP хостинга).

## Логи и рост данных
Docker-логи ограничены: игра 3 × 10 МБ, Caddy 2 × 5 МБ. В базе ежечасно удаляются: ID обработанных событий старше 7 дней, голоса старше суток, итоги голосований старше 30 дней. Состояние игры и очередь ограничены по размеру.

## Перезапуски без бесконечного цикла
Docker перезапускает упавший контейнер с растущей задержкой. Конвейер эфира внутри игры делает не больше 6 попыток за 30 минут (паузы 5 с … 5 мин), затем останавливается и пишет причину в пульт.

## Типовые проблемы
| Симптом | Что сделать |
|---|---|
| Пульт: `stream: failed` | Посмотрите Problems log. Частые причины: неверный ключ или URL (обновите в Stream settings), сеть до Kick. Затем START |
| `Kick sees live: no`, хотя stream live | Проверьте URL и ключ. В Kick Dashboard задайте название и категорию эфира. Подождите 30–60 с |
| `kick: error … HTTP 401` | Неверные Client ID или Secret: введите заново |
| Чат не влияет на игру | Webhook URL в настройках приложения Kick должен совпадать с пультом; Enable Webhooks должен быть включён |
| Подписки пустые | Нажмите Reconnect. Kick отключает webhook после суток недоступности |
| Сертификат не выдаётся | Порты 80/443 должны быть открыты в панели хостинга; DNS-имя должно указывать на сервер |
| Кодер медленный (speed < 1) | Выберите hd24 или sd30, либо включите auto |
| Нет звука в эфире | Проверьте громкость в пульте (Sound). Посмотрите `hvc logs` на ошибки pulseaudio |
| Игра «застыла» | Проверьте, не стоит ли пауза (Game → Resume). Если нет — Restart service |
