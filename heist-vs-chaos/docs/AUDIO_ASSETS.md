# Звук и ассеты

## Происхождение (лицензионная чистота)
- **Графика** нарисована кодом (`src/client/game/art.ts`, `rooms.ts`). Изображений из чужих источников нет.
- **Музыка и звуки** синтезированы кодом (`tools/gen-audio.ts`): две петли (calm, escape) и 25 эффектов.
- **Голос робота** — 50 реплик, синтез espeak-ng с роботизированной обработкой в FFmpeg. espeak-ng распространяется под GPL; лицензия не распространяется на синтезированный звук.
- **Шрифт** Fredoka — SIL Open Font License (пакет @fontsource/fredoka).
- Пересобрать звук: `npm run audio` (нужны ffmpeg и espeak-ng).

## Как подключить свои файлы
Положите файлы на сервере в `/opt/heist-vs-chaos/data/custom-audio/` и перезагрузите страницу эфира: пульт → Maintenance → Restart service, либо STOP и START эфира. Форматы: ogg, mp3, wav, m4a, opus.

| Папка | Имя файла | Эффект |
|---|---|---|
| `music/` | любое | заменяет музыку; первый по алфавиту — спокойный трек, второй — трек побега |
| `sfx/` | `zap.ogg`, `alarm.ogg`, `success.ogg`, … (список в `public/audio/manifest.json`) | заменяет звук |
| `voice/` | `<событие>-<n>.ogg`, например `steal-1.ogg`, `steal-2.ogg` | заменяет реплики события |

События для реплик: intro, vote, success, hurt, noisy, steal, escape, defeat, level, campaign, shield, scan, revive, chaos, auto, revote.

Правила микширования: лимитер на выходе; голос и тревога приглушают музыку; одна реплика звучит не чаще раза в 3 минуты, обычные реплики — не чаще раза в 7 секунд; важные события (кража, победа, поражение) озвучиваются всегда. Текст зрителей никогда не озвучивается.
