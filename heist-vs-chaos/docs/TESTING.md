# Проверки

Запуск: `npm run check` (типы, валидатор уровней, unit-тесты, сканер секретов) и `npm run e2e` (браузер). GitHub Actions выполняет всё это при каждом push, затем собирает Docker-образ и проверяет его запуском.

## Ручные и стендовые (среда разработки)
- **Визуальная проверка** всех 15 механик и анимаций последствий через режим `/?preview=L,B,вариант` (контрольные листы скриншотов).
- **Конвейер вещания целиком** (Xvfb + PulseAudio + Chromium + FFmpeg) → локальный RTMP-приёмник. Принято: H.264 Main 1280×720 30 fps около 3 Мбит/с и AAC 48 кГц стерео; громкость звука −26 дБ в среднем, пики −4 дБ. Кадр из принятого потока совпадает с экраном игры.
- **Процесс на 2 ядрах** (`taskset -c 0,1`): hd30 держит 30 fps при speed 1.00x.
- **Автовозобновление эфира** после перезапуска процесса сервера подтверждено. Счётчик эфирного времени продолжился, а не обнулился.
- **Длительный прогон** эфира с мониторингом памяти — результаты в `docs/SOAK.md`.

## Что не проверено (нужен внешний доступ)
Реальная отправка в Kick, приём эфира на стороне Kick, реальные webhook-и чата и подарков, установка на ваш VPS, получение статуса KICK Streamer. См. [LIMITATIONS.md](LIMITATIONS.md).
