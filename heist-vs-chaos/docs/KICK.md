# Kick

Проверено по официальной документации (docs.kick.com, github.com/KickEngineering/KickDevDocs) 18.11.2026.

## Что нужно и почему
- **Ключ трансляции** (Creator Dashboard → Channel → Stream URL and Key) нужен только для отправки видео. Он вводится в пульте (Stream → Stream settings) и хранится в зашифрованном виде.
- **Чат и подарки** приходят через приложение Kick (Client ID и Client Secret) и webhook. Вход под аккаунтом владельца не нужен: токен приложения может подписаться на события публичного канала по его ID.
- Канал **safarzod** существует (kick.com/safarzod, broadcaster user id 139575365). На 18.11.2026 он не в эфире, 0 подписчиков, статуса стримера нет.

## Один шаг владельца (с телефона)
1. Включите двухфакторную аутентификацию в аккаунте Kick: без неё вкладка разработчика недоступна.
2. Откройте **kick.com/settings/developer** → Create app.
   - Name: `HEIST vs CHAOS`
   - Redirect URL: `https://ВАШ-АДРЕС/auth/kick/callback` (поле обязательное; игра его не использует)
   - Scopes: `events:subscribe` (`channel:read` по желанию)
   - Enable Webhooks: **ON**. Webhook URL: `https://ВАШ-АДРЕС/webhooks/kick` (точный адрес показан в пульте, раздел Kick)
3. Скопируйте Client ID и Client Secret в пульт: Kick → Kick app settings → Save.

В течение примерно 10 секунд статус станет `connected`, а подписки — `chat.message.sent, kicks.gifted, livestream.status.updated`. Плашка AUTO MODE «Chat offline» исчезнет.

## Безопасность webhook
- Подпись: RSA PKCS#1 v1.5 SHA-256 над строкой `messageId.timestamp.rawBody`. Публичный ключ берётся из `GET /public/v1/public-key`, кэшируется на 6 часов и запрашивается повторно, если подпись не сошлась (ротация ключа).
- Неверная подпись → 401. Чужой канал → событие игнорируется. Повтор того же `Kick-Event-Message-Id` → 200 без эффекта. Событие старше суток игнорируется.
- Запоздавшие сообщения чата отсекает логика голосования по времени `created_at`. Запоздавшие подарки всё равно ставятся в очередь и не пропадают.
- Kick отключает подписку, если webhook не отвечает больше суток. Сервер каждые 5 минут проверяет подписки и создаёт их заново.

## Подарки (Kicks)
По умолчанию подарки **не дают игровых эффектов**: на экране просто показывается благодарность. Включается в пульте (Kick → Gift effects), там же задаются пороги. По умолчанию: SCAN от 1, SHIELD от 50, REVOTE от 100, CHAOS от 250, REVIVE от 500 Kicks. Подарок, который сейчас нельзя применить, ждёт в очереди и не теряется. Автоматических возвратов Kick не предоставляет, и игра их не обещает.

## Монетизация и статус
- **KICK Streamer** (бывший Affiliate): по официальной справке нужно 5 часов эфира суммарно. Отсюда лимит первого эфира в 5 часов. Получение статуса проверяйте в Creator Dashboard: через API статус не виден, и игра его не утверждает.
- Выплаты идут только через Stripe. Если Stripe недоступен в вашей стране, Kick не выплачивает деньги и не включает подписки. Есть ли Таджикистан в списке Stripe, подтвердить не удалось: проверьте выпадающий список стран при настройке выплат. Использовать чужой банковский счёт в другой стране запрещено правилами Kick.
- Правила Kick: накрутка ботами запрещена. Игра не создаёт фиктивных зрителей, сообщений и подарков. Для Verified и Partner Kick просит «оригинальный живой контент, не записи». Игра генерируется в реальном времени и интерактивна, но решение о статусе принимает Kick.
