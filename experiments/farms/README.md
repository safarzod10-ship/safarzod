# Фермы HomeBeast — изометрические 3D-установки

Три статичные «майнинг-фермы» в стиле питомцев: светлые бронепанели с контурами,
объёмное освещение граней, трубы, заклёпки, светящиеся акценты, тёмная техно-платформа.
Доход у всех одинаковый — отличается только вид.

| id | Название | Акцент |
|---|---|---|
| `crystal` | Кристальная ферма — модули с трубами и фиолетовыми кристаллами | фиолетовый |
| `server` | Серверная ферма — стойки с серверами, градирни, чиллер, блок питания | синий |
| `reactor` | Реакторная ферма — кристалл-реактор под стеклом, баки, солнечные панели | бирюзовый |

Отрисовка: `js/iso.js` (мини-движок изометрии: коробки, цилиндры, трубы, кристаллы, свечение),
`js/farms.js` (сами фермы). Рендер в прозрачные PNG: `node tools/render.mjs media`
(просмотр: `node tools/serve.mjs 8080` → `index.html?farm=server`).
В мини-апп кладутся WebP 640 px: `miniapp/assets/farms/`.
