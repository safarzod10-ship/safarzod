# Робо-пёс: атака лазерами из глаз (питомец №2)

Второй питомец для Telegram Mini App **HomeBeast**. Нарисован программно на Canvas 2D в
том же стиле, что и робо-дракон (`../dragon`): контуры, бронепластины со швами и
заклёпками, стальные шарниры, глаза-объективы. Палитра — синяя под тему приложения
(`#161a33`, `#3d8bfd`), жёлтый ошейник с жетоном. Это базовый («пустой», 1-й уровень) вид.

## Запуск

```bash
cd experiments/dog
node tools/serve.mjs 8080      # http://127.0.0.1:8080/index.html  (?transparent — без фона)
```

## Персонаж (`js/dog.js`)

- Туловище — одна бронированная «труба» по сплайну (круп → бёдра → живот → грудь → шея),
  серебристый живот и «манишка», батарейная панель на спине: её огоньки показывают заряд лазера.
- Хвост-антенна из 7 сегментов со светящимся шариком, виляет (амплитуда на пружине).
- 4 лапы на двухзвенной IK: лапы стоят на месте, когда пёс приседает.
- Голова: круглый череп, белая маска морды, нос, челюсть на шарнире (лай, дыхание с
  высунутым языком), при открытой пасти видно горло, а спереди — фон; клыки.
- Два глаза-объектива: ближний и дальний (поворот головы к зрителю), оба стреляют.
  В покое светятся голубым, при заряде — красным, зрачок сужается.
- Уши на пружинах с «болтанкой»: настораживаются, прижимаются при заряде, трясутся.

## Последовательность (`js/timeline.js`, 8 с)

| Время | Фаза |
|---|---|
| 0–1.0 | покой: дышит с высунутым языком, виляет хвостом, моргает |
| 1.0–1.6 | замечает цель: уши торчком, любопытный наклон головы, хвост замирает |
| 1.6–2.4 | приседает, злые брови, оскал, рычание |
| 2.45, 2.85 | два гавка |
| 3.05–3.85 | заряд: уши прижаты, частицы втягиваются в глаза, глаза краснеют, огоньки на спине заполняются |
| 3.85–5.85 | два лазера из глаз, голова ведёт лучи вниз-вперёд, удар по земле: вспышка, искры, дым, прожжённый след |
| 5.85–6.8 | отключение, пар из глаз, отряхивается «как мокрая собака» |
| 6.8–8.0 | довольный возврат: хвост виляет сильнее, язык снова наружу, короткий «чирик» |

## Звук (`js/audio.js`)

Всё синтезируется Web Audio: рычание и лай с роботной окраской (кольцевая модуляция +
металлический резонанс), писк заряда, «вжик» включения и гул лучей, треск попадания,
затухание при отключении, пар, сервоприводы, лязг при отряхивании.
