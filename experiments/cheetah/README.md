# Робо-гепард: молниеносный прыжок и удар лапой (питомец №3)

Третий питомец для Telegram Mini App **HomeBeast**. Нарисован программно на Canvas 2D в
том же стиле, что робо-дракон и робо-пёс: контуры, бронепластины со швами и заклёпками,
стальные шарниры, глаза-объективы. Палитра: золотисто-оранжевая броня, тёмные пятна-пластины,
кремовый живот и морда, электрические бирюзовые акценты. Базовый (1-й уровень) вид.

Атака — удар лапой: в рейде гепард берёт скоростью.

## Запуск

```bash
cd experiments/cheetah
node tools/serve.mjs 8080      # http://127.0.0.1:8080/index.html  (?transparent — без фона)
```

## Персонаж (`js/cheetah.js`)

- Длинное поджарое тело одной бронированной «трубой»: глубокая грудь, подтянутый живот,
  тёмные пятна-пластины (во время заряда в них загорается электричество), энергоканал вдоль спины.
- Хвост из 10 сегментов: висит низко с загнутым кончиком, тёмные кольца и чёрный кончик.
- Длинные лапы на IK: в прыжке тело вытягивается (передние вперёд, задние назад),
  передние лапы наносят удары, выпускаются светящиеся когти.
- Маленькая круглая голова с «слёзными» полосками — фирменная черта гепарда, кремовая
  морда, нос, клыки, челюсть на шарнире (рычание, рык), круглые уши на пружинах,
  два глаза-объектива: в покое янтарные, при заряде — электрические.
- Смещение всего тела (root) для прыжка вперёд и рывка назад; во время рывка за ним тянется
  светящийся «фантомный» шлейф.

## Последовательность (`js/timeline.js`, 7.6 с)

| Время | Фаза |
|---|---|
| 0–0.9 | покой: дышит, мурлычет, хвост покачивается, моргает |
| 0.9–1.6 | замечает цель, уши вверх, затем прижимаются; опускается в низкую стойку, рычит |
| 1.7–2.6 | заряд: по лапам и спине бегут молнии, пятна светятся, «виляет» задом перед прыжком |
| 2.62–2.92 | молниеносный прыжок вперёд: тело вытягивается, шлейф, линии скорости, пыль |
| 2.95–3.25, 3.45–3.75 | **два удара лапой** — главный момент: лапа с выпущенными светящимися когтями высоко замахивается перед мордой и с силой бьёт вниз-вперёд; три больших энергетических следа когтей, искры, ударная волна по земле, вспышка и тряска кадра |
| 4.3–4.62 | рывок обратно на место (снова шлейф) |
| 4.95–5.85 | рык (кольца звука, дрожь) |
| 5.85–7.6 | возвращается в покой, снова мурлычет |

## Звук (`js/audio.js`)

Web Audio, без файлов: механическое мурлыканье, рычание с роботной окраской, треск
электрозаряда, «вжух» прыжка и рывка, металлические удары при приземлении, «звон» когтей
с электро-разрядом, рык, сервоприводы.
