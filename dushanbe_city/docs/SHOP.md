# Меню, аккаунт и магазин игровых денег

## Меню при запуске
- `scenes/menu/main_menu.tscn` — главная сцена проекта.
- На фоне — кадр города из самой игры.
- Кнопки: **ИГРАТЬ**, **МАГАЗИН**, **НАСТРОЙКИ** (качество графики), **ВЫХОД**.
- Справа сверху — аккаунт: ID, деньги, кнопка «Скопировать ID».

## Аккаунт
- При первом запуске каждому игроку автоматически выдаётся ID из 8 цифр.
- ID сохраняется в `user://account.json` (`scripts/account/account.gd`).

## Пополнение через администратора (без сервера)
1. Игрок выбирает пакет в магазине, платит администратору и сообщает свой ID.
2. Администратор создаёт код:
   `python3 tools/admin/make_code.py <ID> <сумма в смн>` → например `DX-5000-1D47FE-26782C5D21`.
3. Игрок вводит код в магазине → **АКТИВИРОВАТЬ** → деньги зачисляются.

Код подходит только к одному ID, срабатывает один раз, а сумму в нём подделать нельзя: подпись
HMAC-SHA256.

Пакеты, цены и контакт администратора задаются в `data/shop_packages.json`.

## Важно — безопасность
Без сервера ключ подписи лежит внутри игры (`Account.KEY`). Опытный человек может извлечь его из
APK и делать коды сам.

**Перед выпуском:**
- замените ключ в `scripts/account/account.gd` и в `tools/admin/make_code.py` (они должны совпадать);
- для настоящих продаж нужен сервер, который проверяет оплату и начисляет деньги на ID, либо
  Google Play Billing.
