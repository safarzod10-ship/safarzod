# Стандарт графики

## Рендереры

| Рендерер | API | Когда | Ограничения |
|---|---|---|---|
| **Mobile** (по умолчанию) | Vulkan | Большинство устройств с Vulkan 1.1+ | Нет SSAO, SSIL, SSR, SDFGI, VoxelGI, объёмного тумана |
| **Compatibility** | OpenGL ES 3.0 | Слабые/старые устройства, проблемные Vulkan-драйверы | Дополнительно: нет compute-шейдеров, упрощённые тени и пост-обработка |

Переключение — в диагностике (сохраняется, применяется после перезапуска). Godot также
автоматически откатывается на OpenGL при отсутствии Vulkan
(`rendering_device/fallback_to_opengl3=true`).

## Пресеты (`scripts/graphics/graphics_presets.gd`)

| Параметр | LOW | MEDIUM | ULTRA |
|---|---|---|---|
| Внутреннее разрешение 3D | 70 % | 85 % | 100 % |
| Сглаживание | FXAA | MSAA 2× | MSAA 4× |
| Атлас направленных теней | 1024 | 2048 | 4096 |
| Дальность теней | 40 м | 80 м | 150 м |
| Каскады теней | 1 (ортогональные) | 2 | 4 |
| Мягкость теней | жёсткие | soft low | soft medium |
| Дальность прорисовки (+туман) | 250 м | 500 м | 900 м |
| Порог LOD мешей | 4 px (агрессивно) | 2 px | 1 px |
| Glow | нет | да | да |
| Анизотропная фильтрация | нет | 2× | 4× |
| Ограничение FPS | 30 | 30 | 60 |

Ultra ≠ «всё включено»: используются только функции, поддерживаемые Mobile-рендерером.

## Бюджеты (целевые, подлежат проверке на устройствах)

| | LOW | MEDIUM | ULTRA |
|---|---|---|---|
| Draw calls в кадре | ≤ 300 | ≤ 600 | ≤ 1000 |
| Треугольников в кадре | ≤ 300 тыс. | ≤ 800 тыс. | ≤ 1.5 млн |
| Текстуры персонажа/авто | 1024² | 2048² | 2048² (4096² только hero-объекты) |
| Целевой FPS | стабильные 30 | 30 | 60 (на мощных устройствах) |

**FPS на телефонах не измерялся** — нет устройства. Значения FPS из серверного
программного рендера (llvmpipe, 3–16 FPS) не являются показателем мобильной производительности.

## Ресурсы

* Формат: GLB/glTF 2.0, метры, Y вверх, перед = +Z.
* PBR metallic-roughness: baseColor (sRGB), ORM/RM (G = roughness, B = metallic, линейные),
  normal (OpenGL/glTF, линейная).
* Текстуры сжимаются Godot в VRAM-форматы ETC2/ASTC (`import_etc2_astc=true`).
* LOD генерируется импортёром Godot (`meshes/generate_lods`), для города — HLOD (этап 6).
* Материалы двусторонние только там, где геометрия открыта (Prado, памятник); замкнутые
  меши — односторонние.

## Текущее состояние ресурсов (этап 1)
* Персонаж — полноценный PBR (3 карты 2048²).
* Prado и памятник — **без UV и текстур**, временные однотонные материалы. Это главная
  задача этапа 2 для достижения реалистичного вида.
