Prado = +X; ключи PerformanceMonitor; загрузка обеих тестовых сцен через SceneLoader;

**Найдено и исправлено в ходе тестирования:**
1. Тест-раннер освобождался при смене сцены → зависание. Исправлено (раннер не является текущей сценой).
2. Утечка 4–5 RefCounted при выходе: лямбды на сигналах автозагрузок + `use_sub_threads=true`. Исправлено, `--verbose` показывает 0 утечек.
3. Солнце в тестовых сценах светило снизу вверх (Transform3D в .tscn — построчный). Исправлено, проверено скриптом.
4. Неверная интерпретация `index.count` в формате артефакта (количество индексов, не треугольников). Исправлено.
