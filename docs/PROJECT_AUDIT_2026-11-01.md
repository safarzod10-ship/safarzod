## Открытые проблемы (по приоритету)

### Высокий
1. **Prado выглядит «пластилиново»** [проверено]: 8 материалов без единой текстуры
   (`asset_pipeline_v2.py:183-190`), UV есть, но не используется; нет стекла (всё непрозрачное,
   двустороннее), фары и фонари без эмиссии; нормали источника сглажены через жёсткие рёбра (у
   окраски 37 % углов треугольников с отклонением нормали > 30° от грани, 7.3 % > 60°).
   Исправление по образцу памятника: разделение нормалей по углу ~35°, AO-атлас, прозрачное
   стекло, эмиссивные фары, панели кузова (normal map).
2. **Плоское освещение** [настройки проверены, вид — оценка]: `environment_rig.tscn:30-31` —
   вклад неба в ambient 0.1, остальное постоянный серый (`day_night_cycle.gd`); в Mobile нет SSAO;
   нет ReflectionProbe/LightmapGI. Для памятника это частично компенсировано запечённой AO.
   Рекомендация: вклад неба 0.6–0.8 с перекалибровкой по `lighting_calibration.tscn`,
   ReflectionProbe у площади. **Не менялось** — калибровка этапа 1 сделана по замерам и требует
   повторной проверки, это отдельная задача.
