## Источник

**Артефакт:** https://claude.ai/artifact/V319FyaEBZx5atFp4i7bg3 — версия `1793469013-6165`,
владелец — пользователь проекта. Ссылка предоставлена владельцем проекта в задании этапа 1.

Артефакт — веб-просмотрщик (three.js). Каждая модель хранится как **один** сжатый меш:
`manifest.json` + `geoz00.txt` = base64(gzip(position f32×3 | normal f32×3 | [uv f32×2] | index u32)),
glTF-координаты (Y вверх, UV origin сверху). Формат восстановлен по коду просмотрщика и
подтверждён контрольными размерами `total`/`compressed` из manifest.

Оригиналы скопированы **без изменений** в `source_assets/artifact_V319FyaEBZx5atFp4i7bg3/`

## 1. Toyota Land Cruiser Prado — `assets/vehicles/prado/prado.glb`

| | Источник | После подготовки |
|---|---|---|

| Масштаб | нормализован: длина 1.0 | **×4.4747** → колёсная база 2.79 м (J150) |

**Разделение подвижных частей (надёжно диагностируемо):** колесо = все острова, целиком
лежащие в габарите шины, касающейся земли (шина 1 375 треуг. + диск ~1 220 + ступица ~300
+ 8 гаек), 10–12 островов на колесо; пивот — центр габарита (высота оси 0.45 м). Руль —
отдельное кольцо 1 344 треуг. в салоне. Всё остальное — `Body`.

**Найденные проблемы (не исправлялись автоматически):**
1. **Пропорции не соответствуют реальному Prado.** При базе 2.79 м: ширина 2.43 м
   (реально 1.885), высота 2.17 м (1.83–1.89), длина 4.47 м (4.78–4.84), диаметр колеса
   ≈ 0.89 м (≈ 0.78). Модель «приземистая/широкая» относительно оригинала.
   Неравномерное масштабирование исказило бы колёса — решение на этапе 2.
2. **Передние колёса повёрнуты** (смоделированы с углом поворота; оценка 8–16° в
   зависимости от метода — методы не согласуются, поэтому не выпрямлялось).
3. **Двери, стёкла, фары, салон не отделены**: кузов — один связный остров 23 464 треуг.
   Нет UV → нельзя назначить материалы стекла/краски/хрома по текстуре.
4. 858 неманифолдных рёбер, 3 395 граничных, 178 треугольников с обмоткой против
   нормалей (тонкие элементы) — оставлен двусторонний материал.

**Обоснование масштаба:** по опубликованным данным статуя ≈ 13 м, общая высота с аркой
≈ 43 м; в модели статуя занимает 0.30 высоты → 0.30 × 43 = 12.9 м. Пропорции согласуются.

**Архитектурные элементы (по островам, визуально подтверждено рендером):** арка (19 394
треуг.), статуя со скипетром (9 232), два льва (по ~4 940), корона (4 243 + 1 392 основание),
колонны (по ~710), постамент со ступенями (1 103) и др. Детали сохранены полностью.

**Проблемы:** корона «висит» над аркой с зазором ≈ 1 м (0.881 → 0.904 в единицах модели) —
так в источнике; 2 519 неманифолдных рёбер; нет UV — золото/камень/бронзу нельзя
разделить текстурами (этап 2: материалы по островам + UV).
