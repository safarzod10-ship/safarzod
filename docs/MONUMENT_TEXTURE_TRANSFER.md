# MONUMENT_TEXTURE_TRANSFER — что взято из старого памятника и почему именно это

Задача: использовать текстуры, материалы и детали старой модели (`oldmonument`) для
улучшения текущей, **не перенося вслепую**. Ниже — что проверено, какие числа получены и какое
решение принято для каждого вида данных.

## 1. Что есть в старой модели

| Данные | Факт | Файл |
|---|---|---|
| Геометрия | 1 929 803 треуг., одна оболочка, UV 0…1 | `source_assets/artifact_V319FyaEBZx5atFp4i7bg3/oldmonument/geoz0*.txt` |
| Color | 4096², sRGB, JPEG | `oldmonument/color.jpg` = `assets/monuments/old_monument/old_monument_color.jpg` (SHA-256 `1ad1dc5f…`) |
| Normal | 4096², касательное пространство, PNG | `oldmonument/normal.png` (`c9607f22…`) |
| RM | 4096², G = roughness, B = metallic (glTF) | `oldmonument/rm.jpg` (`7e369ea8…`) |

Файлы артефакта `Hr4rDEPHxsKRtxrHq7E5rV` сверены с репозиторием по SHA-256 — идентичны.

**Раскладка UV** — автоматическая «лоскутная» (тысячи мелких островов, характерные для
автогенерации). Острова не соответствуют архитектурным элементам. Цвет на текстуре: розовый
гранит основания, белая облицовка с золотыми кантами, золотые «сталактиты» и корона; статуя
и львы — серый/коричневый камень.

## 2. Перенос текстур на текущую геометрию — проверка (отрицательный результат)

Перенос (bake «selected → active») корректен, только если поверхности двух моделей совпадают с
точностью порядка размера текселя (сантиметры). Проверено `tools/validation/compare_monuments.py`
(`docs/reports/monument_old_vs_current.json`): для каждого элемента текущей модели соответствующая
область старой модели подогнана преобразованием подобия (ICP с отсечением 15 % выбросов,
Умеяма), затем измерены расстояния между поверхностями в обе стороны.

| Элемент | Поворот после подгонки | Медиана текущая→старая | P90 | Медиана старая→текущая | В пределах 2 см |
|---|---:|---:|---:|---:|---:|
| Статуя (13.3 м) | 14.7° | 0.17 м | 0.50 м | 1.14 м | **2.1 %** |
| Лев левый (5.5 м) | 6.2° | 0.10 м | 0.34 м | 0.23 м | 4.3 % |
| Лев правый | 13.6° | 0.30 м | 0.87 м | 2.21 м | 0.4 % |
| Корона (4.2 м) | 6.1° | 0.22 м | 0.64 м | 3.39 м | 0.3 % |

Наложение облаков точек (`docs/screenshots/monument_v3/comparison/overlay_*.png`) показывает
причину: **другие формы**. У статуи другая поза рук, у львов другая поза (старые лежат,
текущие сидят), у короны другой рисунок зубцов. Вывод: запекание цвета или нормалей старой модели
на текущие статую, корону и арку дало бы чужие детали в чужих местах. **Это не делалось.**

## 3. Что перенесено и как

| Что | Решение | Проверка |
|---|---|---|
| **Геометрия львов** | Взяты **целиком** лежащие львы старой модели: вырезаны выше плоскости верха плинта (y = 0.1205 ед. — доминирующая горизонтальная плоскость под львом, найдена по гистограмме площадей) в измеренной рамке, равномерный масштаб по длине посадочного места текущего льва (5.37 м), посадка на плинт текущей модели | Пропорции Ш:В:Д = 1 : 1.33 : 2.09 и 1 : 1.35 : 2.03; высота 3.43 / 3.58 м против ≈ 3.5 м на фото; оба смотрят вперёд, как на фото. Отчёт: `docs/reports/monument_v3_lions.json` |
| **Normal map львов** (грива, шерсть) | Запечена со старой поверхности (86 тыс. треуг. + её 4K normal map) на децимированный LOD0 (32 тыс.) в новую UV — это **та же поверхность**, поэтому перенос точный | Луч 4 см / 12 см; отклонение XY карты: среднее 0.024, P99 0.22 (видимая деталь, без шума выбросов) |
| **Цветовая схема** | Старая модель подтвердила то, что видно на фото: розовый/красный гранит основания, светлая облицовка арки, золото только по кантам и внутри проёма. Цвета взяты **не из её текстуры** (у неё произвольный баланс белого и «нарисованные» тени), а из фото (`MONUMENT_MATERIALS.md` §2) | — |
| Цвет/RM текстуры старой модели | **Не используются**: запечённое освещение и тени в color-карте, статуя и львы окрашены как камень (на фото — бронза), разрешение 4096² на всю модель = 0.9 см/тексель «мыла» | — |

Оригиналы не изменены: `assets/monuments/old_monument/*` (в APK не входит),
`source_assets/artifact_V319FyaEBZx5atFp4i7bg3/oldmonument/*`. Вырезанные львы в высоком
разрешении (с упакованными старыми текстурами) — `source_assets/monument_v3/lions_from_old_hi.blend`.

## 4. Новые UV текущей модели

v2 имела один Smart-UV без использования. В v3 три непересекающихся атласа с одинаковой
плотностью внутри атласа (`docs/reports/monument_v3_build.json`, поле `bake`):

| Атлас | Объекты | Площадь | Размер | Плотность | Перекрытие UV |
|---|---|---:|---:|---:|---:|
| sculpt | статуя, скипетр, детали, корона, чаша | 341 м² | 2048² | 1.42 см/тексель | 0.28 % |
| lions | 2 льва | 94 м² | 2048² | 0.65 см/тексель | 0.11 % |
| arch | платформа, постамент, плинты, арка, рейки, колонны, антаблементы | 5 659 м² | 4096² | 4.31 см/тексель | 0.53 % |

Перекрытие измеряется растеризацией треугольников UV (512², центры текселей). Остаток долей
процента — касания соседних треугольников на швах. Отклонённый вариант: конформная пере-развёртка
кусков 3 × 3 м дала «покрытие» 80 %, но с массовыми перекрытиями. На рендере это были тёмные
пятна на облицовке, поэтому вариант отброшен. Принятый: временный разрез по сетке 3 м + Smart UV
(не перекрывает) + перенос UV по полигонам.
