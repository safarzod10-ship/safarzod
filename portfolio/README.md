# Bob Proger — сайт-портфолио

Одностраничный сайт: сайты, Telegram-боты, Mini Apps и игры.
Чистые HTML/CSS/JS, без сборки. Все библиотеки и шрифты лежат внутри папки, интернет-CDN не нужен.

## Как посмотреть локально

```bash
cd portfolio
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом тоже можно, но шрифты в некоторых браузерах грузятся только через сервер.

## Как выложить в интернет

Подойдёт любой статический хостинг. Загрузить нужно **содержимое папки `portfolio/`**:

- **Netlify / Vercel** — перетащить папку в окно «Deploy» или подключить репозиторий и указать папку `portfolio`.
- **GitHub Pages** — Settings → Pages → источник: ветка, папка `/portfolio` (или перенести файлы в корень / `docs`).
- **Обычный хостинг** — залить файлы по FTP в `public_html`.

После выкладки замените в `index.html` строку
`<meta property="og:image" content="assets/og.jpg">` на полный адрес, например
`https://ваш-домен.ru/assets/og.jpg` — тогда превью ссылки в Telegram будет с картинкой.

## Что где менять

| Что | Где |
| --- | --- |
| Тексты, названия проектов, описания, ссылки | `index.html` (каждый проект — блок `<article class="work">`) |
| Отзывы | `assets/js/reviews.js` — вставить отзывы в массив `REVIEWS`, поменять `REVIEWS_URL` на ссылку канала с отзывами |
| Цвета проекта | атрибуты `data-color` и `style="--c:…;--ink:…"` у `<article class="work">` |
| Общие цвета, шрифты, отступы | начало `assets/css/style.css`, блок `:root` |
| Жидкий фон в первом экране | `assets/js/gl.js` (WebGL-шейдер) |
| Мини-игра в карточке «Зуба-Руба» | `assets/js/game.js` |
| Все анимации | `assets/js/main.js` |

## Анимации

- Прелоадер: счётчик 0→100 и «лог деплоя», затем шторки уезжают вверх.
- Первый экран: WebGL «жидкий хром», который закручивается вокруг курсора;
  буквы имени меняют толщину (variable font) рядом с курсором; вращающееся слово.
- Плавный скролл (Lenis) и сцены на ScrollTrigger (GSAP).
- Манифест «загорается» по словам при прокрутке.
- Бегущая строка ускоряется и наклоняется от скорости скролла.
- Карточки работ складываются стопкой, фон секции перетекает в цвет проекта.
  Внутри карточек живые макеты: чаты ботов печатают сообщения, лазер «стирает» тату,
  VPN-кнопка подключается, мини-игра играет сама (кликом можно прыгать).
- Аккордеон услуг с заливкой, горизонтальный скролл этапов работы.
- Футер «выезжает» из-под страницы, огромное имя поднимается.
- Кастомный курсор с подписями, магнитные кнопки, «перебор букв» на ссылках.
- Учитывается `prefers-reduced-motion`: при отключённых анимациях сайт статичный и читаемый.

## Библиотеки

GSAP 3.15 (+ ScrollTrigger, SplitText, CustomEase), Lenis 1.3 — в `assets/vendor/`.
Шрифты Unbounded, Onest, JetBrains Mono (OFL) — в `assets/fonts/`.
