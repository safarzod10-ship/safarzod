# Джарвис — офлайн-помощник для Android

Голосовой помощник на русском: разговаривает, звонит, пишет сообщения, говорит погоду, открывает приложения, ищет в интернете, ставит будильники и напоминания, управляет фонариком, громкостью и музыкой, запоминает, кто есть кто («мама — это контакт Mom»).

Распознавание речи, память и нейросеть работают **на телефоне** — без серверов и подписок. Интернет нужен только для поиска, погоды, YouTube и (по желанию) загрузки нейросети.

## Установка

1. Скачайте `Jarvis.apk` на телефон и откройте его.
2. Разрешите установку из этого источника, если Android спросит.
3. При первом запуске Джарвис по шагам попросит разрешения. Обязательно — только микрофон.
4. Скажите «Джарвис» или нажмите на ядро.

Требования: Android 8.0+, OpenGL ES 3.0. Нейросеть — только на 64-битных телефонах (arm64), модель «Умная» — от 6 ГБ ОЗУ.

## Что внутри

| Часть | Как сделано |
|---|---|
| Слово «Джарвис» и команды | Vosk, русская модель (офлайн), кольцевой буфер — «Джарвис, позвони маме» можно сказать на одном дыхании |
| Понимание команд | Правила на русском (падежи, числа словами, время, калькулятор) — мгновенно, без нейросети |
| Нейросеть (по желанию) | Qwen 2.5 через MediaPipe — понимает необычные фразы и поправляет текст сообщений |
| Голос | 55 записей из `sounds/incoming`, нормализованы; где записи нет — текст + звуковой сигнал |
| 3D-ядро | Два шейдера OpenGL ES 3.0: «Плазма» и «Нейросфера». Когда Джарвис говорит — волнуются в такт голосу, крутятся пальцем |
| Синтез голоса | Piper/VITS, дообученный на записях, через sherpa-onnx: Джарвис говорит любой текст без интернета |
| Разговор | Локальная Qwen 2.5: отвечает на вопросы голосом, по предложениям, прямо во время генерации |
| Погода | Open-Meteo (без ключей): «Сейчас в Москве плюс четыре, пасмурно…» |
| Сообщения | «Напиши маме, что я не приду» → «Привет, мама! Я не приду.» |
| Настройка голоса | Чтение 5 фраз: чувствительность к «Джарвис», свои варианты обращения, отпечаток голоса (режим «только мой голос») |
| Кнопка «Стоп» | Полностью выключает реакции: микрофон, ответы, объявления — до «Включить» |
| Память | Локальный JSON: обращения к контактам и приложениям, напоминания |

## Добавить свои звуки

- В приложении: **Настройки → Библиотека голоса → «+»** у нужной ситуации (mp3/ogg/wav/m4a).
- Или в проект: положите файл в `sounds/incoming`, впишите его в таблицу `CLIPS` в `tools/build_voice.py` и запустите `python3 jarvis/tools/build_voice.py`.

## Сборка

```bash
cd jarvis/android
./gradlew :app:assembleRelease          # модель Vosk скачается сама при первой сборке
./gradlew :app:testDebugUnitTest        # тесты разбора команд + скриншоты экранов (app/build/screenshots)
```

Для подписи нужен `keystore/keystore.properties` + `keystore/jarvis-release.jks` (в git не хранятся). Без них релиз подписывается отладочным ключом.

Инструменты:
- `tools/build_voice.py` — обработка голосовых записей (обрезка тишины, громкость, огибающая для анимации).
- `tools/build_sfx.py` — синтез звуков интерфейса.
- `tools/shader_preview/render.js` — рендер 3D-ядер в браузере для проверки дизайна.
