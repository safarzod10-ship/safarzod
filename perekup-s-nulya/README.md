# «Перекуп с нуля» — анимационный сериал для TikTok

Вертикальное видео 1080×1920, 30 fps. Персонажи и сцены нарисованы кодом (Canvas) в `episode1.html`.

## Файлы
| Файл | Что это |
|---|---|
| `episode1.html` | Серия 1: анимация + плеер (открыть в браузере, пробел — пауза) |
| `render.js` | Рендер HTML → MP4, субтитры SRT и обложка |
| `fonts/Rubik.ttf` | Шрифт (SIL OFL, см. `fonts/OFL.txt`) |
| `out/` | Результаты рендера (в git не попадают) |

## Как отрендерить
```bash
node render.js episode1.html                    # out/episode1.mp4, .srt, _cover.png
node render.js episode1.html --shots 5,40,100   # отдельные кадры для проверки
```
Нужны Node, Playwright (Chromium) и ffmpeg.

## Видео с готовой озвучкой
Записи голоса кладутся в `out/voice/ep1/` (в git не попадают), привязка фраз к субтитрам —
в `voice/ep1_map.json`. Анимация подстраивается под темп голоса, рот персонажей двигается
по громкости записи, реплики «Голоса в трубке» проходят через телефонный фильтр.
```bash
python3 build_voice.py episode1.html voice/ep1_map.json out/ep1_voice   # голосовая дорожка + тайминг
node render.js episode1.html --voice out/ep1_voice                       # MP4 со звуком (-14 LUFS)
```

## Как озвучить
1. Открой `out/episode1.mp4` в CapCut.
2. Читай текст ниже по таймкодам (субтитры уже в видео, по ним удобно попадать).
3. Реплики других персонажей можно озвучить другим голосом или через «Озвучку текста» в CapCut.
4. Добавь фоновую музыку тихо (10–15 %) и звуки: «дзынь» на 1:40, звонок на 2:48.
