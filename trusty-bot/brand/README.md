# TRUSTY: логотип

Знак: фигурные скобки `{ }` (код, разработчики), сложенные в щит (защита сделки). Внутри щита
монета USDT: деньги, которые гарант держит между клиентом и разработчиком. Зазоры сверху и снизу
показывают, что деньги приходят от клиента и уходят разработчику. Усики скобок стоят на одной оси
с центром монеты.

## Цвета

| Токен | HEX | Где используется |
|---|---|---|
| Emerald | `#178A66` | основной цвет бренда: аватарка, иконка, акцентные поверхности |
| Tether | `#26A17B` | монета на белом и тёмном фоне |
| Deep | `#0B2A27` | тёмные поверхности (тёмная тема Mini App) |
| Ink | `#0D2C27` | знак и текст на светлом фоне |
| Mint | `#E8F5EF` | светлые поверхности, знак на Deep |
| White | `#FFFFFF` | знак и монета на Emerald |

Шрифт надписи: **Onest ExtraBold** (OFL), трекинг +24/1000. В SVG надпись переведена в кривые.

## Файлы

- `logo/avatar-square.svg`, `logo/png/telegram-avatar-640.png`: аватарка бота (квадрат, Telegram сам обрезает в круг)
- `logo/lockup-on-*.svg`: знак с надписью для светлого, тёмного и изумрудного фона, плюс одноцветный вариант
- `logo/mark-*.svg`: только знак
- `logo/app-icon.svg`, `logo/png/app-icon-1024.png`, `apple-touch-icon-180.png`, `favicon-*.png`
- `logo/construction.svg`: построение знака на сетке
- `logo/animation/`: анимация. HTML-версия живая (`?theme=emerald|dark|light`), MP4 1920×1080 и 1080×1080 по 60 кадров/с, GIF 480 px

## Как получен знак

`process/round1` … `round5`: 208 эскизов → 30 → 16 гибридов → 6 → 3 → финал. Скрипты лежат в `tools/`:

```bash
cd tools
python3 round1.py ../process/round1/svg      # эскизы раунда 1 (аналогично round2–5)
python3 final.py ..                         # финальные SVG
python3 anim.py ..                          # HTML-анимации
node export_png.js ../logo                  # PNG
node capture.js ../logo/animation/trusty-intro.html <frames> 1920 1080 60 emerald   # кадры → ffmpeg
```

Нужны Python 3 + fonttools, Node + Playwright, ffmpeg.

Внимание: знак ₮ с кольцом принадлежит Tether. Для аватарки и интерфейса это нормально. Если логотип
будут регистрировать как товарный знак, монету нужно заменить на нейтральную (в `final.py` за это
отвечает функция `coin_symbol`).
