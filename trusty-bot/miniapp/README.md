# Trusty Mini App: прототип

Кликабельный прототип Mini App на тестовых данных. Оплаты и сервера пока нет, всё хранится в памяти.

## Что есть

| Раздел | Экраны |
|---|---|
| Главная | приветствие, поиск, «Создать проект», направления, кто сейчас в сети, новые проекты, «Как работает гарант» |
| Разработчики | поиск по стеку и имени, фильтры (в сети, свободны, направления), сортировка; карточка: рейтинг, сделки, % в срок, когда был в боте, время ответа |
| Профиль разработчика | гарантии (личность, GitHub, залог, споры), о себе, портфолио, последние сделки с отзывами, «Написать», «Предложить проект», жалоба |
| Проекты | лента и «мои проекты/отклики», создание проекта с проверкой полей, отклик разработчика, выбор исполнителя → сделка |
| Чаты | список с бейджами сделок, чат с карточкой сделки, системные сообщения, предупреждение при попытке увести сделку «в личку» |
| Профиль | роль «заказчик / разработчик», анкета разработчика (4 шага), мои жалобы |
| Жалобы | причина, описание, скриншоты-доказательства |
| Админ-панель | очередь жалоб, решение: бан 30 дней (первое нарушение) или навсегда (повторное), отклонение, список людей, баны и разбан; администраторов максимум 2 |

Внутри Telegram используются нативные кнопки «Назад» и MainButton/SecondaryButton, вибрация и тема Telegram.
В обычном браузере те же действия показываются кнопками внизу экрана.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/
node scripts/tour.mjs shots light   # скриншоты всех экранов (нужен Playwright)
```

## Подключение к боту

Telegram открывает Mini App только по HTTPS.

1. Соберите `npm run build` и выложите `dist/` на любой статический хостинг с HTTPS (свой сервер с nginx + Let's Encrypt,
   GitHub Pages, Netlify, Vercel).
2. В @BotFather: `/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → отправьте ссылку.
3. Там же **Menu Button** → отправьте ту же ссылку и подпись «Открыть», чтобы кнопка появилась рядом с полем ввода.
