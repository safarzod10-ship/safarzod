TERRIA — спрайты зданий 2.5D, версии 1–5.
Все PNG вырезаны из общего визуального каталога (источник включён) и увеличены до холста 512×512.
Это предварительные ассеты: у мелких элементов возможны неточные края. Проверьте в PixiJS перед релизом.
Размещение ориентируйте по сетке tiles из manifest.json; позиционирование спрайтов — снизу по центру.
