# TERRIA — план графики и живой деревни

Цель: здания уровня Clash of Clans, деревня, которая живёт, и всё это плавно в Telegram.
Работаем шагами: делаем одну вещь, проверяем в игре, исправляем, идём дальше.

## 1. Как делаются здания

- **Модель — моя, кодом в Blender** (`tools/blender/`). Для каждого здания есть
  скрипт, который строит модель из настоящих деталей: камни кладки, брусья,
  черепица рядами, окна с рамами, двери, трубы. Детали со скруглёнными гранями,
  материалы с разбросом оттенка, мягкий свет, тени.
- **Один ракурс для всего** (`kit.py`): ортографическая камера, 45° по кругу,
  30° над землёй. Это ровно ромб 2:1 карты. Солнце слева сверху, тень вправо.
  Все здания и все уровни снимаются одной и той же камерой и одним светом.
- **Прозрачность**: рендер сразу с прозрачным фоном и тенью на земле
  (shadow catcher). Ничего не вырезается вручную, краёв с ореолом нет.
- **Привязка к участку**: скрипт сам считает, где на картинке центр участка
  и какой ширины его ромб, и точки для эффектов (верх трубы, флаг, дверь).
- **Конвейер**: `townhall.py` → `art/blender/render/townhall_1.png + .json` →
  `tools/blender/cut.mjs` (обрезка по видимым пикселям) → `tools/art/pack.mjs`
  (атлас) → игра.
- **Уровни (до 10)**: каждый уровень — отдельный рендер. Внутри одного здания
  уровни растут: больше этажей, богаче материалы (дерево → камень → кирпич →
  мрамор, солома → черепица → сланец → медь), новые детали (башня, часы,
  купол, флаги). Ромб участка у всех уровней один.
- **Разнообразие**: у каждого типа свой силуэт и своя гамма крыши, чтобы
  здания не были на одно лицо. На участках нет деревьев и зелени.

## 2. Анимация (отдельные спрайты поверх здания)

| Что | Как |
|---|---|
| Дым из труб | частицы PixiJS из точки `smoke*` в .json |
| Флаг | 8–12 кадров ткани из Blender, цикл |
| Мельница | лопасти отдельным спрайтом, вращение |
| Двери | 3–4 кадра открывания, когда входит житель |
| Урожай | 4 стадии роста грядок на ферме |
| Жители | фигурки из Blender: ходьба 8 кадров × 4 направления |
| Стройка | леса и леса с подъёмом здания снизу вверх, пыль |

## 3. Экономика

Производство, потребление, склады и улучшения уже считает общее ядро
(`src/game/rules.ts`, сервер — источник истины). Дальше: 10 уровней для
ратуши и зданий и перебалансировка симулятором (`tools/balance/sim.ts`) на
~3 месяца игры.

## 4. Живая деревня (без дорог)

- Жители выходят из домов, идут к месту работы по свободной земле участка
  (обход зданий по сетке клеток), работают, возвращаются.
- Фермы растят урожай по стадиям, мельница крутится, из труб идёт дым,
  у мастерских стучит работа.
- Всё это — только картинка: экономика от анимации не зависит.

## 5. Оптимизация

- Атласы по типам зданий, загрузка по требованию (только то, что есть в
  городе и рядом).
- Разрешение спрайта под максимальное приближение (≈150 px на клетку),
  мипмапы для дальних видов.
- Частицы и жители — пулы объектов, без выделения памяти каждый кадр.
- Проверка: телефонный размер экрана, FPS-панель, тесты, сборка, затем
  выкладка.

## Порядок

1. Ратуша уровня 1 → показать → поправить по отзыву.
2. Остальные уровни ратуши.
3. Жилой дом, ферма, лесопилка, карьер, шахта … по одному, каждый с уровнями.
4. Дым, флаг, стройка; потом жители и урожай.
5. 10 уровней в экономике и баланс.
