# HomeBeast — Telegram Mini App

**Один файл со всем проектом:** `dist/homebeast.html` (сборка: `python3 tools/build_single.py`).
Открывается напрямую, без сервера: внутри весь код, питомцы и фермы.

Основа — присланный `index.html` (экраны: Главная, Питомец, Рейд, Инвентарь, Магазин, NFT).

## Первый вход

1. **Рулетка питомца** (лента карточек «как открытие кейса», указатель по центру,
   хаптик-тики в Telegram на каждой карточке) выбирает одного стартового питомца.
2. Сразу после — **такая же рулетка фермы**.
3. Кнопка «В игру!» — игрок попадает в главное меню.

Выбор сохраняется (Telegram `CloudStorage`, без Telegram — `localStorage`), при следующих
входах рулетки не показываются. `index.html?reset` — сбросить и пройти выбор заново (для тестов).

## Данные (`<script>` в конце `index.html`)

- `PETS` — питомцы, готовы 3 из 5: робо-дракон, робо-пёс, робо-гепард. Новый питомец = ещё
  одна строка (картинка в `assets/pets/`).
- `FARMS` — 3 фермы: Кристальная, Серверная, Реакторная. **Доход у всех одинаковый**
  (`FARM_RATE` = 5 монет/мин), отличается только вид. Статичные изометрические 3D-картинки
  в `assets/farms/` (исходник и рендер — `experiments/farms/`).

Где показывается выбор: сцена на «Главной» (ферма + питомец), экран «Питомец» (питомец,
имя, атака), «Инвентарь → Питомцы» (ячейка 1).

## Живые питомцы (`js/petview.js`)

На «Главной» и на экране «Питомец» питомцы не картинки, а настоящие риги (`js/pets/` — тот же
код, что в анимациях атак) в **спокойной позе**: дышат, моргают, водят хвостом, кивают, у пса
высунут язык и виляет хвост. Позы атаки используются только для атак.
Все питомцы рисуются в **одном масштабе** (`PET_DEFS[...].unit`): дракон самый крупный, пёс и
гепард меньше, все меньше фермы. Пример: `docs/home_idle_pets.mp4`.

## Важно

Рулетка и начисление дохода сейчас на клиенте — это заглушка для прототипа. В боевой
версии результат рулетки и баланс должен выдавать сервер (иначе их можно подделать).

## Быстрая механика (прототип, клиент)

- **Главная:** доход фермы копится в хранилище (кап 2 000), кнопка «Собрать» переводит его в баланс;
  таймер «До рейда» (окно 20:00–22:00 МСК, в окне — «Рейд идёт!»).
- **Питомец:** статы по виду (дракон — сила, пёс — защита, гепард — скорость), сытость падает
  ~4%/ч, «Кормить» за 50 монет (+35%), ниже 30% сила ×0.5; «Броня +10%» за 500 монет.
