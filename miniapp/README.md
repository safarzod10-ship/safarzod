# HomeBeast — Telegram Mini App

Основа — присланный `index.html` (экраны: Главная, Питомец, Рейд, Инвентарь, Магазин, NFT).

## Первый вход

1. **Рулетка питомца** (лента карточек «как открытие кейса», указатель по центру,
   хаптик-тики в Telegram на каждой карточке) выбирает одного стартового питомца.
2. Сразу после — **такая же рулетка фермы**.
3. Кнопка «В игру!» — игрок попадает в главное меню.

Выбор сохраняется (Telegram `CloudStorage`, без Telegram — `localStorage`), при следующих
входах рулетки не показываются. `index.html?reset` — сбросить и пройти выбор заново (для тестов).

## Данные (`<script>` в конце `index.html`)

- `PETS` — питомцы, готовы 3 из 5: робо-дракон, робо-пёс, робо-гепард. Новый питомец = ещё
  одна строка (картинка в `assets/pets/`).
- `FARMS` — 3 фермы: Гараж-ферма, Серверная башня, Солнечный купол. **Доход у всех одинаковый**
  (`FARM_RATE` = 5 монет/мин), отличается только вид. Анимированные SVG в `assets/farms/`.

Где показывается выбор: сцена на «Главной» (ферма + питомец), экран «Питомец» (картинка,
имя, атака), «Инвентарь → Питомцы» (ячейка 1).

## Важно

Рулетка и начисление дохода сейчас на клиенте — это заглушка для прототипа. В боевой
версии результат рулетки и баланс должен выдавать сервер (иначе их можно подделать).
